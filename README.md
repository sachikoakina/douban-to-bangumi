 Douban → Bangumi：GitHub Actions 运行方案将豆瓣“看过”列表中的电影/剧集匹配到 Bangumi，并同步为“看过”和对应评分。采用 Bangumi 官方 HTTP API，不依赖 Tampermonkey、浏览器 DOM 或 iframe。 两阶段运行1 **plan**：采集豆瓣、搜索 Bangumi、计算匹配置信度，生成 Artifact `output/planjson`，不写收藏。2 下载并审核计划。`matched` 会执行，`needs_confirmation` 和 `skipped` 不执行。3 将审核后的文件以 `planjson` 放到仓库根目录，运行 **sync**。结果上传为 `output/resultjson`。已 `synced` 的条目重跑时跳过。 一次性配置在仓库 Settings → Secrets and variables → Actions 添加：- `BANGUMI_ACCESS_TOKEN`：Bangumi 个人 Access Token。- `DOUBAN_COOKIE`：可选，豆瓣登录 Cookie。运行 Actions → Douban to Bangumi → Run workflow，`mode=plan`，填写豆瓣用户 ID。 行为约定- 仅同步豆瓣“看过”到 Bangumi“看过”，API `type=2`。- 豆瓣 1–5 星转换为 Bangumi 2、4、6、8、10 分。- 候选限制为 Bangumi 动画（2）和三次元（6）。- 低于 70 分跳过；剩余条目可人工确认。- 默认 Bangumi 请求间隔 1 秒，豆瓣翻页至少 5 秒。- Artifact 不包含 Token/Cookie。
